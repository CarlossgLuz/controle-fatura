# Security Policy

## Supported Scope

Este projeto recebe reportes relacionados a:

- vazamento de dados locais
- manipulacao indevida de persistencia
- execucao insegura de links externos
- falhas que impactem integridade de dados financeiros

## Como Reportar

Nao publique vulnerabilidades sensiveis em issues abertas antes de contato inicial.

Use um canal privado do mantenedor do repositorio e inclua:

- descricao do problema
- impacto esperado
- passos de reproducao
- ambiente afetado

## Observacao

Atualmente o projeto usa armazenamento local. Qualquer uso em producao deve considerar endurecimento adicional de seguranca.
